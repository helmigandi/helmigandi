Format Hard Disk di Linux

25 Maret 2026, 07:38

Berikut adalah cara untuk format hard disk di Sistem Operasi Linux dengan menggunakan sistem file exFAT.

exFAT adalah sistem file (file system) ang digunakan untuk mengatur data pada media penyimpanan agar bisa diakses di Windows, Linux, dan macOS.

Format Windows macOS Linux Max File Size
NTFS Didukung Hanya Baca Butuh Driver 16 TB
exFAT Didukung Didukung Didukung 16 EB
exFAT Didukung Didukung Didukung 4 GB

I. Cara Memformat


          # 1. Install exFAT tools (if needed)
          sudo apt install exfatprogs   # Ubuntu/Debian
          # sudo dnf install exfatprogs # Fedora

          # 2. Unmount the disk
          sudo umount /dev/sda1

          # 3. Create a new GPT partition table (better than MBR/dos)
          sudo parted /dev/sda --script mklabel gpt

          # 4. Create a single partition using the full disk
          sudo parted /dev/sda --script mkpart primary 0% 100%

          # 5. Format to exFAT
          sudo mkfs.exfat -n "MyDrive" /dev/sda1

          # 6. Verify
          sudo fsck.exfat /dev/sda1

          # 7. Fix the partition type to official Microsoft Basic Data GUID
          sudo gdisk /dev/sda
          
          # 8.  Inside gdisk:
          # 9.  t        → change partition type
          # 10. 1        → select partition 1
          # 11. 0700     → Microsoft Basic Data (correct for exFAT/NTFS)
          # 12. w        → write and exit
          # 13. y        → confirm
