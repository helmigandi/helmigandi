Konversi Youtube Video Musik dengan Audacity

24 Mei 2026, 08:50

Berikut adalah cara untuk mengkonversi video musik untuk YouTube menggunakan Audacity.

Langkah-langkah

  1. Download video/audio menggunakan yt-dlp.
  2. Buka Audacity dan impor dengan cara drag and drop file audio/video yang telah di-download.
  3. Potong bagian yang tidak diinginkan.
  4. Set Normalize ke -1.0 dB (default).
  5. Export file audio.

Pengaturan Normalize

  1. Select file atau blok dengan menggunakan Ctrl dan a.
  2. Pilih menu Effect dan kemudian pilih Volume and Compression terakhir klik Normalize.
  3. Pastikan nilai normalize diatur ke -1.0 dB, centang Remove DC offset dan jangan mencentang normalize stereo channels independently.

Pengaturan Konversi atau Export Audio

  1. Pilih format MP3
  2. Pada bagian Audio Options dan pastikan pengaturan seperti berikut:
    • Channels: Stereo
    • Sample Rate: 48000 Hz
    • Bit Rate Mode: Preset
    • Quality: Extreme
