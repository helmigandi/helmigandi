Perbaikan Gagal Booting Arch Linux Setelah Update

29 November 2025, 17:45

Setelah melakukan update pada Arch Linux, saya mendapati sistem tidak dapat melakukan booting dengan benar dengan error terkait Error: "initrd: not found" / Boot Device Not Found.

Gejala

  1. Setelah update dan reboot, sistem tidak bisa boot
  2. Muncul pesan error terkait ../systemd/src/boot/boot.rc: 2630@call_image_start: error parsing initrd: not found
  3. Terakhir, stuck pada screen "HP boot device not found".

Penyebab

File initramfs hilang atau rusak (initramfs-linux.img dan initramfs-linux-fallback.img), biasanya setelah update kernel.

Langkah Perbaikan

1. Boot dari Arch Linux Live USB

  1. Siapkan Arch Linux Live USB. Jika belum punya, buat menggunakan panduan Cara Membuat Bootable Flashdisk di Linux.
  2. Boot komputer dari Live USB tersebut.

2. Mount Partisi Root Sistem Arch Linux


          # Periksa partisi
          lsblk

          # Mount partisi root (biasanya yang besar, contoh: 475GB) atau bisa di /dev/sdaX
          mount /dev/nvme0n1p2 /mnt

          # Mount partisi EFI/boot (biasanya 1GB) atau biasanya di /dev/sda1
          mount /dev/nvme0n1p1 /mnt/boot

          # Verifikasi file boot ada
          # Harus muncul: EFI, loader, vmlinuz-linux, intel-ucode.img
          ls /mnt/boot

3. Masuk ke Sistem Menggunakan Chroot

arch-chroot /mnt

4. Perbaiki mkinitcpio.conf yang Rusak


          # Hapus konfigurasi yang rusak
          rm /etc/mkinitcpio.conf

          # Install ulang paket
          pacman -S mkinitcpio --overwrite /etc/mkinitcpio.conf

5. Regenerate Initramfs

mkinitcpio -P

Harus muncul pesan: Initcpio image generation successful

6. Install Ulang Bootloader


          # Untuk systemd-boot (paling umum)
          bootctl install

          # Peringatan "not booted with efi" boleh diabaikan

7. Keluar dari Chroot dan Reboot


          # Keluar dari chroot
          exit

          # Unmount semua
          umount -R /mnt

          # Reboot
          reboot

Setelah reboot, sistem Arch Linux harusnya bisa booting normal kembali.

8. Sedikit Pencegahan


          # Sebelum update, cek ruang di /boot
          df -h /boot  # Pastikan ada ruang cukup

          # Update
          yay -Syu

          # Setelah update, sebelum reboot
          ls -lh /boot/initramfs*  # Verifikasi file ada

          # Jika hilang
          sudo mkinitcpio -P

          # Reboot

Kesimpulan

Gagal booting setelah update di Arch Linux biasanya disebabkan oleh file initramfs yang hilang atau rusak. Dengan mengikuti langkah-langkah di atas, masalah ini dapat diperbaiki dengan mudah.
